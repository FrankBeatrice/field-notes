Every archive needs a first page.

This one begins simply: a title, a date, and a few paragraphs written in Markdown. There is no publishing dashboard to learn. No database to maintain. The file itself is the post.

## Write plainly

Create a new file inside `_posts` using this pattern:

`YYYY-MM-DD-your-title.md`

Then add the small block of metadata at the top — title, subtitle, category — and write beneath it.

> A good personal site should make publishing feel lighter, not heavier.

When the repository is pushed to GitHub, Pages builds the site automatically. The archive updates itself. The newest piece moves to the front page.

That is the whole system.
